# Godot 0.3.0 验收

## 自动化

- Godot 4.6.1 实际引擎导入与脚本解析。
- `tests/run_tests.gd`：44 项模型/存档/计时检查，涵盖深度上限、昼夜、稳定 ID、重复操作、满缸替换、取消/无效替换不丢鱼、放生保留图鉴、会话与待安置鱼获恢复、v1 迁移、备份恢复、未知版本不覆盖、睡眠间隔与重复采样不补计。
- `--tests --ui-smoke`：Godot 实际主场景与控件初始化，放钩、收杆、保留鱼获、鱼缸/图鉴面板及按钮状态，满缸取消和确认替换。
- `tests/windows_focus_smoke.ps1`：Windows 运行真实 Win32 查询脚本，核对状态字段、token、时效与清理。不能替代真实锁屏/休眠验收。
- GitHub Actions：Windows 导出、导出程序启动检查及下载产物。

运行命令见根目录 README。

## Windows 实机验收

- 独立窗口运行：放钩后切到其他应用，约每分钟 4 米；回到游戏立即暂停。
- 图鉴、鱼缸、确认弹窗在前台时不累计。
- 空闲超过 10 分钟暂停；恢复操作后继续，不补计暂停间隔。
- 锁屏、安全桌面、睡眠、远程断开暂停；恢复后保留深度，不补计间隔。
- 重复放钩不清空深度，重复收杆不增加图鉴次数。
- 满缸取消保留两条鱼；确认仅替换目标个体。放生保留图鉴。
- 收杆后退出再打开，待安置鱼获不变；进行中的会话可恢复。
- 备份后破坏主存档：恢复备份；未知版本原文件不变。
- 系统禁用 PowerShell 或查询进程异常：显示检测不可用并保守暂停。

最终 V2.6 美术、真实鱼种生态与体长分布不属于本轮验收通过项。
