# 0.2.0 验收记录与实机清单

## 自动化验证

`npm run verify` 包含深度上限、专注条件、昼夜候选、稳定鱼种 ID、抽取范围、鱼缸容量、重复操作防护、鱼缸满位替换、放生保留图鉴、会话和鱼获恢复、v1 迁移、损坏存档备份恢复、未知版本保护，以及素材清单验证。

`node --check` 检查 main/preload/renderer 和 shared 模块语法。Windows GitHub Actions 安装 Electron、运行 verify 并生成 portable exe。

当前执行环境没有本地 Chromium/Electron 桌面环境，未完成渲染截图与真实桌面交互验收。逻辑通过不代表 Windows 系统事件和最终美术已验收。

## Windows 试玩

- 启动、放钩、切换工作窗口：有效分钟约增加 4 米；游戏前台和图鉴/鱼缸面板停留不计时。
- 键鼠空闲超过 10 分钟：暂停；恢复输入后继续。锁屏、睡眠、唤醒不得补计间隔。计时在连续有效采样之间累计，切换时会有短暂采样延迟。
- 重复放钩不会清空当前深度；重复收杆不会新增图鉴次数。
- 收杆后关闭程序并重启：显示同一条待安置鱼获；必须安置后才能放钩。
- 收进鱼缸后重复点击不能再次领取；同种不同个体可以各占一格。
- 满缸收杆：取消替换保留 6 条旧鱼和新鱼获；确认替换仅移走所选个体。
- 放生确认取消不改变数据；确认放生保留发现次数和纪录。
- 重启恢复会话深度，退出期间不累计。
- 复制存档后手动破坏主文件：恢复备份；未知 version：提示并暂停，原文件不变。
- 窗口缩到 850 × 650：内容可滚动，弹窗能关闭，键盘 Tab/Enter/Escape 可操作。
