# Windows 第一阶段验收 · v0.3.1

状态：2026-10-13 用户报告第一阶段已验证、无问题，已进入第二阶段。以下保留逐项复测模板；未提供的具体时长与实测数值不补写。

## 准备

- 解压 Windows 构建包，运行 DesktopFishing.exe；若使用编辑器，关闭嵌入游戏，使用独立窗口。
- 退出旧实例，不要同时运行两个版本。先备份 `%APPDATA%/DesktopFishingGodot/`。
- 默认空闲宽限为 10 分钟，可在主界面改为 5 / 10 / 20 分钟，设置立即保存。
- “检测与诊断”可查看状态、最近保存时间、复制最小诊断或重试检测。诊断不包含按键内容、窗口标题、应用使用历史。
- 当前模型在手动收杆时抽鱼。暂停保留专注秒数、深度与会话；收杆后保留同一个待安置鱼获。

## 存档恢复专项（仅在备份后，用测试存档）

1. 玩出一份测试存档，保存两次，退出。备份 save.json 与 save.json.bak。
2. 把 save.json 改成 `{broken`，启动：提示从备份恢复，能继续保存；备份不会被坏主文件覆盖。
3. 分别让两份文件都损坏，启动：暂停操作，保护原文件；允许直接退出。
4. 用未知版本如 `{"version":999}` 作主存档：应暂停保护，不能偷偷回退覆盖。
5. 测试保存失败：使用单独 Windows 测试账户/目录，暂时禁止该账户写存档目录，尝试改设置或退出；设置不应被提交，退出应取消。恢复权限后重试。不要在唯一的正式存档上操作。
