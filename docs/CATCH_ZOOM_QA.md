# 0.8.1 大图鱼获、百科与浮窗缩放

## 操作
- 未放竿/已结算鱼获时，时钟右侧播放按钮＝放竿并开始番茄钟；专注中＝暂停，已暂停＝继续。动画中、完成待起竿、待安置鱼获时避免重复开始。
- 鼠标停在模式二/三窗口内滚轮向上放大、向下缩小，每档10%，范围75%–200%，并受当前显示器工作区限制；两种模式分别保存。
- 缩放以鼠标所在位置为锚点，保留逻辑坐标、计时、鱼获和动画。工具条、设置与鱼获卡片独立保持可读大小。右键菜单提供恢复100%。
- 极简模式待机、垂钓、收短线时，浮漂与竿尖保持同一X坐标；放竿抛投保留自然弧线。

## 卡片
340×600奶白卡片；鱼插画按实际非透明边界等比适配大图，源PNG没有修改。collection_manifest.json新增display_rect，工具scripts/tools/update_portrait_bounds.py可重新生成。忽略Alpha≤8的近透明杂点并保留8像素安全边距。
首次发现/新纪录、体长、专注时长、第几次相遇和图鉴完成度动态读取真实存档；揭晓后静止。百科区域可独立滚动，底部入缸/放生/稍后安置固定保留。已发现鱼种也可在图鉴回看知识。

## 百科
14个稳定ID全部有生态介绍与趣味知识。群体名不擅自指定成某个具体物种，虚构星愿鱼明确标记游戏彩蛋；游戏体长不等同真实物种尺寸范围。
来源逐条记录在data/fish-introductions.json的sources字段，包括NOAA Fisheries、Smithsonian Ocean、Monterey Bay Aquarium、FishBase、Animal Diversity Web与seahorse.org。文案为中文归纳；新增百科未改变鱼池概率或鱼种ID。

## 验证
新增catch_zoom_tests覆盖时钟放竿、防重复、待安置保护、缩放边界/分别记忆/状态保留、垂直线与百科数据。catch_zoom_capture检查14张卡片的按钮边界，并渲染75/100/200%两种模式及3张代表卡片。
16组本地headless回归通过。Windows CI加入专项验证、实际渲染、物理滚轮和时钟放竿测试，最终结果以本PR Actions为准。多屏/DPI仍需实机验收。
