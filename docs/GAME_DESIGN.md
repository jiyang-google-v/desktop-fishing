# Desktop Fishing · MVP 设计基线

定位：工作时安静陪伴，休息时获得惊喜。主循环：放钩 → 切到其他应用工作 → 深度随有效专注增长 → 返回游戏 → 收杆盲盒 → 图鉴/精选鱼缸。

- 真实生态型：鱼池由水深决定，时间分昼夜；稀有度为权重而非绝对承诺。
- 0–200m，4m/有效分钟；当前工程采用收杆时一次抽取的 MVP 简化模型，未来的水下停留遭遇事件仍待细化实现。
- 图鉴记录发现鱼种、最大体长纪录；鱼缸只展示玩家主动选择的最多 6 条鱼。
- UI：主场景占优，简洁放钩/收杆按钮，图鉴/鱼缸为覆盖面板。
- 暂不包含：老板来了按钮、背包、商店、货币、等级、天气、悬浮窗。
