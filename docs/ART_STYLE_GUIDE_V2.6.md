# Desktop Fishing 美术标准 V2.6 — 柔和粉彩海洋绘本

## 最高优先级参考
`assets/references/PRIMARY_REFERENCE_V2.6.jpg` 是用户最新确认的**唯一最高优先级视觉原稿**。此前偏鲜艳的参考图及 V2.4/V2.5 的冲突条款失效。原稿只定义视觉语言，图中背包、48 图鉴等元素**不自动成为 MVP 功能**。

## 核心风格
温柔、轻盈、低至中饱和的 2D 海洋童话游戏插画；柔和粉彩/轻水彩质感，细微纸绘纹理，圆润简化的 Icon 形态。优先保证与原稿的整体氛围、配色、密度、线条一致，而非单个资产的精致度。

## 颜色
- 主色：雾蓝、柔和青蓝、薄荷青绿；辅助：奶油白、淡珊瑚粉、浅杏黄、薰衣草紫。
- 色彩偏浅、略带灰度；避免电光蓝、荧光青、纯高饱和橙、强对比大色块。
- 明暗柔和，背景层级清楚但不厚重；海水可有淡淡颗粒与层次。
- 颜色必须在原稿场景中视觉校准，不机械套用固定色值。

## 描边
- 根据主体自适应颜色：蓝鱼蓝紫线、粉鱼柔粉紫线、橙鱼柔棕橙或灰蓝线；**不统一蓝线**。
- 轮廓连续、清晰、适度轻柔；不能因粉彩晕染而丢失主体边界。
- 线宽随显示比例调整，轻微手绘不规则感；不使用硬黑粗描边或锐利矢量切边。

## 造型与纹理
- 鱼：紧凑 Icon 轮廓、点眼、少量识别性花纹，尽量简化鱼鳍；不画写实鳞片。
- 人物/猫：比例亲切，细节克制，少量柔和表情。
- UI：奶白面板、浅雾蓝描边、低对比柔和阴影、轻微圆角；保持轻盈。
- 特效：淡青白波纹、小水滴、柔和微光，避免手游技能般高亮爆发。
- 纹理：允许细腻粉彩、水彩边缘，但绝不牺牲 32–96px 的识别度。

## 禁止项
高饱和亮蓝、荧光色、塑料/玻璃高光、厚重立体阴影、复杂写实水彩、强光晕、重描边、统一描边颜色、3D、像素风、过度细节化。

## 视觉验收（必做）
1. 参考原稿同屏对照，检查色相、饱和度、对比度、线条和细节密度。
2. 在真实青蓝水体和奶白卡片上分别以 32、48、64、96px 预览鱼与图标。
3. 角色、UI、特效必须在场景内组合预览，不只看单独素材。
4. 若风格偏离，标记 `style_rejected`，不可称为正式资产。

## 正式美术资产技术门槛（独立于视觉验收）
- 每个组件/动作帧为独立 RGBA PNG，必须实际检测 Alpha 通道，棋盘格背景不算透明。
- 统一画布、朝向、显示比例、锚点、连续帧命名。
- 动画提供真实可解析 `.animation.json`，资产提供 `asset_manifest.json`。
- 必须在实际游戏显示尺寸验收、检查透明边缘和无裁切；全部通过才标记 `production_ready`。
- 单张概念拼图、未切分的 sprite sheet 或仅写在图上的文件名不算交付。

## 范围约束
保留既定 12 鱼 ID；水母、墨鱼为扩展生物，墨鱼不能用章鱼代替。MVP 不新增背包、金币、等级、天气、老板按钮；桌面悬浮组件属于后续探索。
