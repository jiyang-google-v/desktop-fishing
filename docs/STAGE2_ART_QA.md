# 第二阶段美术与交互验收 · v0.4.0

最高依据：`ART_STYLE_GUIDE_V2.6.md`、`ART_PRODUCTION_STANDARD.md` 和唯一参考原稿。首批主场景使用内置 imagegen 生成的独立组件，未把概念拼图作为运行时 UI。

## 本批 G1–G4

| 门槛 | 检查与证据 | 结果 |
|---|---|---|
| G1 风格 | 对照参考原稿检查海洋绘本造型、粉彩纸绘纹理、色相与描边；在场景内使用轻奶油色覆盖进一步降低背景对比，UI 为奶白与雾蓝细边 | 内部检查通过，等待用户视觉反馈 |
| G2 文件 | 三张独立 RGBA PNG，尺寸/锚点/右向写入 manifest；背景覆盖全画布，叠加层真实透明；详见 `qa/stage2/asset-checks.json` | 通过 |
| G3 动画 | JSON 实际控制放钩/收杆时长、鱼竿角度、呼吸周期、海面与气泡参数；不声称为逐帧动画集 | 通过 |
| G4 集成 | 真实 Godot OpenGL 渲染检查昼/夜、放钩/收杆、最小窗口；检查透明边缘与手部/码头/鱼线/浮漂对接 | 通过 |

Alpha 检查同时记录全部非零像素与 Alpha>16 的可见轮廓。生成素材外围存在极低透明度粉彩纹理，可见主体四边有留白；真实场景检查未见白边、黑边或裁切。

参考图仅是风格依据，其背包、48鱼种等元素未加入游戏。本批是第二阶段场景资产，不等于美术标准中的全部八个生产批次。

## 交互保证

- 操作先成功保存，再播放动画；动画期间禁用重复放钩/收杆。
- 鱼获仅在收杆动画完成/跳过后展示；关闭游戏后恢复同一个已保存鱼获，不重抽。
- 专注暂停时探索气泡和鱼线微动冻结，轻环境动画与用户主动操作动画继续。
- 音效默认静音，开启状态保存；海水底声与动作声音使用低音量程序合成，关闭立即停播。
- 主按钮在小窗口可见，设置与诊断可在侧栏滚动访问。
- 第一阶段95项测试、第二阶段动作/资源检查及实际控件交互测试需通过；Windows CI继续验证系统检测和导出程序。
