# 专注计时与状态
- 仅手动放钩后可累计有效专注。
- 游戏窗口前台暂停；游戏后台且电脑醒着、未锁屏、距最后一次键鼠输入不超过 600 秒时累计。
- 电脑锁屏/睡眠暂停；恢复后不补计睡眠时间。
- 深度 = 有效专注秒数 × 4/60，最大 200m；收杆按当前深度和本地昼夜抽取鱼。
- Windows 使用 PowerShell 调用 Win32 `GetLastInputInfo`、`GetTickCount` 返回空闲秒数；游戏前台由 Electron `isFocused` 判定，不读取按键或窗口标题。
- 无法读取状态时保守暂停；其他平台暂不支持。

## 0.2.0 计时与恢复
- 使用单调时钟计算采样间隔；仅两个连续有效采样之间累计，单次超过 5 秒的异常间隔不补计。
- 前后台切换、锁屏、睡眠和会话操作令在途查询失效，防止旧结果为新会话累计时间。
- 进度封顶 3000 秒 / 200 米。重启保留放钩会话，但不补计退出时间。
