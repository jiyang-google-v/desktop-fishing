# 用户自定义专注与系统暂停

当前规范为 POMODORO_SPEC.md。旧后台、键鼠空闲、4m/分钟规则已失效。

Godot每秒以单调时钟和墙上时钟的有效间隔累计番茄钟完成时间。任一间隔超过5秒、非正数或二者差超过1秒时暂停，排除休眠/进程挂起和系统时间跳变，不补计。正常计时与前台/键鼠无关。

Windows PowerShell常驻进程仅查询WTS会话和输入桌面是否可用；保守处理锁屏、安全桌面与断连。每0.5秒发布随机token、采样序号、UTC时间、locked及epoch。不调用GetLastInputInfo或GetForegroundWindow，不收集输入内容、应用名或窗口标题。foreground=false和idle_seconds=0仅保留旧样本校验字段，不参与计时。

epoch在锁定状态变化或系统采样间隔异常时增加；即使Godot漏掉中间锁定采样，epoch变化也会暂停。工作进程退出、样本损坏/过期、token不符/停滞导致保守暂停和自动重试。恢复后需手动继续。

用户退出期间不计时，重新打开未完成挑战保持暂停。暂停/继续和失败确认使用存档事务。锁屏/休眠/high-DPI/远程会话仍须用户设备实机验收，CI只覆盖样本、生命周期及时间间隔模拟。
