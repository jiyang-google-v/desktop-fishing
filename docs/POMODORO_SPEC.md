# v0.7.0 番茄钟钓鱼规则

用户2026-10-14明确授权替代旧专注/深度机制。专注由用户自定义，不验证是否实际工作。

## 挑战状态

待设定 → 放竿计时 → 暂停/继续 → 完成待起竿 → 待安置鱼获 → 下一轮。

- 整数分钟15–120，默认25，快捷25/45/60。放竿后时长固定，计时也从放竿开始。
- 前台、后台、图鉴、鱼缸、键鼠无操作都计时。
- 手动暂停、系统锁屏/会话断开、休眠/时钟异常、检测失败都暂停；解锁、唤醒和重启不自动继续。
- 暂停和退出不累计，重启保留剩余时间并暂停；完成状态重启仍可起竿。
- 提前起竿先确认失败，取消不改变状态；确认后无鱼获/图鉴记录，回到待设定。
- 完成后等待手动起竿，不自动抽鱼/启动下一轮。延迟起竿不改变放竿时锁定的鱼池。
- 计时完成保存；提醒沿用声音开关，默认静音。

## 独立鱼池与概率

每档仅抽对应组，普通/少见/稀有权重6/3/1，无跨组、保底或未收藏加权。完成必得本组一条鱼，允许重复。

|---|---|---|---|---|
|A|15–29|小丑鱼/蓝倒吊鱼/蝴蝶鱼|各6|各25%|
|A|15–29|海马/水母|各3|各12.5%|

## 三态与图鉴

完整模式提供设定、鱼池预览、剩余时间、暂停/继续、提前起竿/完成起竿与收藏管理。两种浮窗工具条提供当前组/剩余时间、暂停/继续、起竿、模式切换、图鉴与鱼缸。图鉴按A/B/C/事件筛选，显示时长和组内最终概率。
