# 悬浮功能整合（模式二 / 三）

## 范围
第五版验收基线：GitHub e182ef0；独立分支 feat/floating-complete。模式一暂留，模式二/三均可独立完成原有工作流。

| 原完整模式功能 | 模式二 / 三入口 |
|---|---|
| 15–120分钟设定、25/45/60预设、分组鱼池预览 | 工具条「设置」或点击时钟 |
| 开始、提前结束确认、完成后起竿 | 放竿 / 起竿 |
| 暂停 / 继续 | 时钟右侧按钮及设置面板 |
| 跳过当前动画、声音 | 设置面板 |
| 真实鱼获、放生、入缸、满缸替换、稍后安置 | 共用翻卡鱼获窗口 |
| 图鉴筛选、鱼缸管理 | 工具条及设置面板；收藏页可相互切换 |
| 置顶、诊断、复制诊断、重试检测、保存退出 | 设置面板；F8仍可保存退出 |
| 保存失败、暂停原因等状态 | 设置面板、时钟提示、收藏页错误提示 |

## 计时修复
- 锁屏样本文件由后台每500ms写入；Godot在同一有效序号内再次读取原先会立刻返回「锁屏/不支持」，现在复用不超过3秒的有效样本。
- 原子替换的短暂读取空档采用有效缓存；缓存过期后短期只冻结未验证时长，不永久锁定暂停。10秒持续失联仍暂停并重试；真实锁屏、休眠、重启仍需手动继续。
- 计时采用单调时钟，系统时间/NTP校准不会误触发休眠暂停；超过5秒的单调时钟中断仍不补计。worker的间隔阈值与之统一。
- 不记录键盘内容、窗口标题或应用历史。

## 视觉与动效
- 模式二原图保持，水下基座补平、底部统一到582/640设计坐标，小圆角收边。
- 图鉴/鱼缸采用奶白窗口、浅蓝描边、共享导航、收藏进度、浅蓝插画卡片，沿用生产鱼与鱼缸图层。
- 极简模式保持无人物小水面，复用第五版贝塞尔跃鱼节奏、水花/水滴；鱼线收短，下一轮才抛出；翻卡直接复用同一窗口，揭晓后静止。

## 验证
本地15组headless回归通过。新增floating_complete_tests覆盖重复样本、读取空档、超时、时钟校准、两种悬浮模式设置与真实鱼获流程。实际Godot/OpenGL截图见docs/qa/floating-complete。
Windows CI新增专项测试、真实尺寸截图和设置入口/时长/声音的物理鼠标验证；最终Windows结果以对应PR Actions为准。多屏、DPI、真实锁屏/休眠、长期挂机仍需人工实机验收。
