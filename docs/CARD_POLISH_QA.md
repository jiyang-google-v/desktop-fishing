# 0.8.2 页面与卡片验收

- 用户参考截图用于卡片的信息层级和配色：奶白底、蓝边、大鱼插画、粉色发现徽章、居中鱼名与稀有度、数据分区。保持现有柔和插画，不切换像素风；没有存档支持的重量字段不虚构。

- 每次正常启动进入模式二，保留各模式的缩放/位置/透明度设置。测试模式为既有整页回归保留完整布局，另有启动模式选择断言。

- 番茄钟达到设定时长显示“可以收竿了”，保持手动起竿、必得鱼及原计时规则。
