# 模式二/三操作与鱼获展示

基于 PR #13 的平底场景，遵循 V2.6 / 场景 V2.7 的现有美术标准；共用原有番茄钟与安置状态，没有新增鱼池或提前起竿收益。

- 新增放竿、透明度按钮，简洁SVG沿用仓库矢量Icon系统；场景和卡片不透明度30%–100%，工具条保留100%，每种浮窗独立持久化。
- 移除功能条暂停、剩余时间及分组，常驻A卡片仍提供计时与暂停/继续。
- 起竿读取已经保存的鱼获，用现有独立鱼PNG上浮及程序气泡；演出后展示260×320原生透明鱼获卡片。满缸进入原有替换界面，保存失败保留待安置鱼获，取消放生保留鱼获，稍后安置可重新打开。
- 模式切换在鼠标释放后延迟执行，隐藏并重建原生工具条；避免复用调整尺寸后的输入窗口。计时/鱼获不归工具条所有。
- 本地Godot4.6.1：14组headless回归通过，新增交互测试覆盖放竿、早收取消、只揭晓一次、模式切换保留鱼获、安置、关闭重开、满缸替换、取消放生、保存失败和36次布局切换。
- 实际OpenGL原生窗口交互回归通过；两浮窗各4张实际尺寸截图，覆盖工具条、60%不透明度、起竿中与鱼获卡片；已逐张检查，并断言滑杆百分比和底部操作不被窗口裁切。
- Windows CI将执行完整验证、导出、启动、透明合成，以及12次scene/mini按钮切换、回完整窗口、放竿、透明度滑杆、完成起竿和收进鱼缸的实际鼠标测试。最终结果以PR检查为准。

人工待验收：高DPI、多显示器位置/缩放、真实锁屏休眠、用户桌面环境下反复切换后输入。自动回归不替代这些实机项目。
