# 人物、猫、钓具与特效补齐

以已合并的 v0.5.0-preview / PR #5 为基线，保持冻结玩法与 V2.6 原稿。

| 类别 | 动作与数量 | 接入位置 |
| --- | --- | --- |
| 小渔 | idle 4、cast 6、reel 6、happy 6，共22帧 | 默认、放钩、收杆、揭晓后短暂高兴 |
| 猫 | idle 4、blink 4、alert 4、happy 4，共16帧 | 待机、定期眨眼、钓鱼动作时留意、鱼获后反应 |
| 钓具 | 鱼竿、浮漂、鱼钩、水桶4个独立PNG | 手部锚点、水面、鱼线末端、码头 |
| 特效 | splash 8、ripple 8、bubbles 6、glimmer 6、shadow 6，共34帧 | 入水、浮漂水纹、水下气泡、钩端微光、水下鱼影 |
| 场景适配 | 无猫无桶码头 | 避免与独立猫/桶重复 |

动画分镜原图保留在 art/concepts/motion/；角色按Alpha连通轮廓提取、特效按固定格提取，统一透明画布与脚点，导出每帧独立RGBA PNG，不用重复静态图冒充帧。素材画布、锚点与时间由 motion.animation.json 定义，真实运行时读取。

G1：原稿同屏、奶白/青蓝底32/48/64/96px、日夜场景。G2：独立PNG/RGBA/留白/连续编号。G3：JSON引用、帧变化、循环首尾及动作节奏。G4：放钩/收杆/跳过/重复操作/小窗口、实际动画预览与截图。通过前保持 integration_candidate，不提前声明全部完成或Windows实机验收。
