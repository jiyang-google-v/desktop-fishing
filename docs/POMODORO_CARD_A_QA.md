# A 方案番茄钟资产与悬浮模式接入

2026-10-14 用户确认 A 卡片，并授权模式二、三正式美术与集成。基于 feat/reference-scene-refresh（17a6764），保留最新场景和既有番茄钟玩法；本 PR 仅包含新增卡片。

## 交付

- 13 个独立 RGBA PNG：太阳、月亮、奶白圆角底板、进度槽/填充、暂停/继续各四态（默认/悬停/按下/禁用）。每个文件尺寸、中心锚点、SHA256 见 assets/production/pomodoro_manifest.json。
- 太阳/月亮由 imagegen 基于 V2.6 原稿和用户批准 A 图生成，保留真实透明度，统一到 128×128 画布；底板和交互纹理沿用项目代码原生 UI 制作方式，SVG 可编辑，build_pomodoro_ui.gd 可重新导出 PNG。数字和状态实时渲染，不烘焙。
- 模式二：420×280，卡片位于右上 (244,2)，164×68，底边留在杆尖上方；不遮人物、猫和灯塔。
- 模式三：为容纳完整 A 卡片，窗口由160×100扩展为180×176；卡片168×70位于上方，原160×100鱼竿场景位于(10,76)，原资产/锚点/朝向不变。
- 独立共享卡片读取 Game 状态：待放竿、专注中、已暂停、专注完成、待安置。按钮发出已有暂停/继续指令。昼夜沿用本地时间（06:00–18:00太阳，其余月亮）。切换布局不重置挑战；图鉴/确认窗口打开时卡片仍刷新。
- 左键点击卡片不触发窗口拖动；卡片不弹出悬停工具条。原场景/鱼竿悬停操作、右键菜单及完整模式保留。
