# V2.6 场景资产

本批包含三个独立 RGBA PNG：完整不透明背景、真实透明码头与猫、真实透明角色。保持原始像素尺寸与统一右向，通过清单记录画布、锚点和渲染用途。背景本身需要覆盖全画面，Alpha 为 255；两个叠加层必须包含真实 Alpha=0 区域。

`scene.animation.json` 是运行时读取的图层补间配置。无伪造逐帧图片，完整角色22帧/猫16帧批次不在本批内。鱼竿、鱼线、波纹、气泡、柔光和云层为 Godot 实时绘制的效果。

技术检查和实际 Godot 截图见 `docs/STAGE2_ART_QA.md`。`production_ready` 仅表示本批在 G1–G4 内部检查通过，不代表用户已逐张确认，也不代表全部八批素材生产完成。
